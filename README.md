# Online Examination System

A GUI-based Online Examination System developed using Java Swing.  
The application provides a simple and interactive platform for students to log in, update their profile, attempt a timed MCQ examination, and view their results.

## Features

- Student Login
- Profile Update
- Java MCQ-based Examination
- Four Multiple Choice Options
- Next and Previous Question Navigation
- 30-Minute Countdown Timer
- Automatic Submission when Time Expires
- Manual Exam Submission with Confirmation
- Result Dashboard
- Score Calculation
- Correct, Incorrect and Unanswered Questions
- Time Taken Display
- Window Close Confirmation during Examination
- Logout Functionality
- Colorful and User-Friendly GUI

## Technologies Used

- Java
- Java Swing
- AWT
- Object-Oriented Programming (OOP)
- Eclipse IDE
